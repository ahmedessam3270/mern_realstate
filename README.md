Ahmed State
Ahmed State is a platform for trading, renting, and selling properties. Users can create their own property listings, upload images, and provide details such as whether the property is furnished, the number of bedrooms, bathrooms, and the availability of parking spots. State owners can also offer discounts to attract potential buyers or renters.

Features
Property Listings: Users can create and manage property listings.
Image Uploads: Upload images to showcase properties.
Property Details: Include details such as furnishing status, number of bedrooms, bathrooms, and parking availability.
Discounts: State owners can provide discounts to attract potential buyers or renters.
Search Functionality: Search properties based on rent, sale, discount, and furnished status.
